🕷️ Mouse Tracking Spider

An Interactive Web Animation Built with HTML & CSS

A creative and interactive spider animation project that brings a virtual spider to life through mouse-based interaction.

This project explores web design, animation, styling, and interactive user experiences using frontend technologies.

✨ Features

- 🕷️ Interactive spider animation
- 🖱️ Mouse-based interaction
- 🎨 Custom visual design
- ⚡ Smooth visual effects
- 🌐 Runs directly in a web browser
